# Pairhaven 1.0 TEST
Native Java/Canvas Android 8+ Toichika facing-arrow-pair puzzle.

Place exactly one arrow in each outlined room. Every arrow must face a partner along a clear row or column, with no arrow between them. Paired rooms must not share an edge anywhere on the board. All arrows belong to a pair; no unpaired arrows. Sightlines may cross at empty cells and pass through other rooms. Gold arrows are fixed. Tap cycles up, right, down, left, empty. Twelve unique 4x4 six-room boards have twelve distinct solutions, three arrow pairs per board.

Saved pair palette and A-F room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens the browser.

Independent Python pairing enumeration proves one solution per board. Java coordinate-pair and whole-region adjacency oracle checks every room-by-room arrow-position combination with all potentially facing directions, plus 30000 random 0-4 cell arrays per board, against production first-arrow ray checks.
